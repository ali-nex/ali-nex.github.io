// crafting digital experiences & systems

It started in 2016 with a second-hand laptop, a C++ compiler and too much curiosity. I broke a lot of things — most of them mine — and slowly learned that software is less about typing code and more about managing complexity.

University sharpened the fundamentals: algorithms, databases, operating systems. But the web is where everything clicked. Shipping something a stranger can use within seconds — that addicted me early.

Since then I've worked across startups and scale-ups, from scrappy MVPs to platforms serving tens of thousands of users daily. I still get the same kick from a well-placed requestAnimationFrame.

Performance is a feature

Budgets enforced in CI, not vibes checked in prod. If it janks, it's broken — perception is the product.

Simple scales, clever fails

The best code is boring. I optimise for the engineer who reads it six months from now — usually me.

Details compound

A 100ms easing tweak, a cleaner empty state. Small polish, multiplied across every user, is the moat.
